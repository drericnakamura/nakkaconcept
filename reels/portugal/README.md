# Portugal — Quando alguém questionou o protocolo

Histórias portuguesas de quem olhou para a regra e perguntou "e se fosse
diferente?". Cada episódio conta a ideia, mostra até onde a evidência foi e
termina no que muda na clínica de hoje. Os episódios são independentes.

Formato, regras e checklist: [../README.md](../README.md). Modelo de roteiro:
[../ep01-figado.md](../ep01-figado.md).

## Correção em relação à pauta original

A pauta dizia "1998" para o All-on-4. As fontes apontam para um intervalo
entre 1993 e 1996 para os primeiros casos, e a primeira publicação é de 2003.
Por isso a narração diz "anos noventa".
